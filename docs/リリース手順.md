# リリース手順（開発用）

| | ファイル | URL |
|---|---|---|
| 本番 | `index.html` ほか（`lots3d.html`・`lots3d.js`・`models/`） | https://kumanohikage.github.io/roulette-dx/ |
| 確認用 | `dev/` の中の同じファイル | https://kumanohikage.github.io/roulette-dx/dev/ |

1. 直すのは `dev/` の中だけ。push すると1〜2分で確認用に出る（`?preview` で演出確認モード）
2. 本番に出すときは `dev/index.html` の `const VERSION` を上げ、`dev/` の `index.html`・`lots3d.html`・`lots3d.js`・`models/` をリポジトリの直下へコピー
3. コミット・push・タグ（`vX.Y.Z`）・`gh release create`
4. 管理の部分の検査: `python -m http.server 5190` を動かして `electron scripts/check-ui.js`
