# ルーレットDX

なんでも決められる、派手な Web ルーレットです。今日の夕ごはん、順番決め、罰ゲーム、配信の企画などに。
インストールは要りません。ブラウザで開いてそのまま回せます。

- 開発中の確認版: https://kumanohikage.github.io/roulette-dx/dev/

## 使い方

1. 右の「候補」の欄に候補を書いて「登録」（改行でまとめて書けば、1行ずつ候補になります）
2. 「SPIN!」で回す
3. 決まったら画面をクリック（または Space）で戻る

- 候補のチェックを外すと、盤から外れます（灰色で一覧に残り、チェックで戻せます）
- 「当たったら外す」をオンにすると、当たった候補が順に外れていきます（順番決めに）
- 盤の真ん中に画像を乗せられます（名前の下の「画像」。ドラッグで位置、ホイールかつまみで拡大。貼り付けやドロップでも入ります）
- 組（候補のまとまり）はいくつでも持てます。左上の組の名前から、切り替え・新しい組・複製・削除
- 内容はブラウザの中に保存されます（どこにも送りません）

### キー操作

| キー | すること |
|---|---|
| Space / Enter | 回す・結果を閉じる・PUSH |
| Delete | いま当たった候補を盤から外す |
| F | 全画面 |
| H | 盤だけの表示（配信向け）／戻す |

## 配信で使うとき

OBS では「ウィンドウキャプチャ」でブラウザを映すか、「ブラウザ」ソースにアドレスを入れてください。
H キーで盤だけの表示にできます。

## 隠し仕様

組の名前に、ある言葉が入っていると見た目が変わります。

| 名前に入っている言葉 | 変わるもの |
|---|---|
| 将棋・棋・駒・王手・詰み・竜王・名人・対局 など | 将棋のテーマ（駒の演出・評価値バー） |
| 闇・絶望・罰・地獄・呪・悪夢・奈落・終焉 など | 闇の見た目 |
| 両方 | 将棋の闇 |

たとえば「罰ゲーム」は闇、「将棋の闇」は将棋の闇になります。どれも見た目と演出の絵柄が変わるだけで、当たる確率は変わりません。

## 当たり方について

当たる候補は、回した瞬間にブラウザの暗号用の乱数で、どの候補も同じ確率で決まります。リーチや全回転などの演出は、決まった結果を見せ方で盛り上げているだけで、結果は変えません。
